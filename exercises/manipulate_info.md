# Manipulating information

This is the last exercise, so use any remaining time for something fun
using iterators, loops, and conditionals in the Puppet language. There
is no prescribed exercise, but the facilitator is available to help with
whatever you choose to attempt.

Some suggestions are listed below:

* Print out the lyrics to the ['99 bottle of beer'](https://en.wikipedia.org/wiki/99_Bottles_of_Beer) song.
* Run through the first 100 iterations of [Fizz Buzz](https://en.wikipedia.org/wiki/Fizz_buzz).
